# CEJUP · Círculo de Estudios sobre Justicia Penal

Página web del Círculo de Estudios sobre Justicia Penal (CEJUP), organización estudiantil de la carrera de Derecho de la Universidad Científica del Sur.

- Todo el sitio está en `index.html` (HTML y CSS, sin dependencias).
- Los colores y tipografías se cambian en el bloque `:root` al inicio del `<style>`.
- Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
